# Documentação técnica — Little Ville

Esta pasta vai reunir a documentação técnica completa do projeto (requisitos funcionais e não funcionais, regras de negócio, arquitetura, entidades, relacionamentos, endpoints, autenticação/autorização e decisões técnicas), conforme o item 32 do briefing do projeto.

**Status atual:** o backend (autenticação, CRUD, comentários, curtidas, denúncias, notificações, dashboard, upload) e o frontend (todas as telas principais) já estão implementados — ver `README.md` na raiz do projeto para instalação, execução e o resumo de funcionalidades.

Esta documentação detalhada será produzida na Etapa 8 do desenvolvimento, depois da integração real entre frontend, backend e banco de dados e da rodada de testes/correções.
